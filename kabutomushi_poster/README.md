# 🪲 かぶとむしの そだてかた ポスター（5まい）

小学2年生でも読める漢字だけ・ふりがな無し・大きな文字でつくった、**自由研究にそのまま使える学習ポスター**です。すべて正方形（1:1）のベクター画像（SVG）なので、A4でもA3でも、印刷しても文字がボケません。

## ファイル

| No. | ファイル | 内容 |
|----|----------|------|
| 1 | `01_house.svg` | 二階建ての かぶとむしハウス（2かい＝食べる・歩く／1かい＝寝る・もぐる、マット10〜15cm） |
| 2 | `02_care.svg` | お世話の 7つの コツ（日かげ・水・ゼリー・のぼり木・フン・けんか ほか） |
| 3 | `03_lifecycle.svg` | かぶとむしの 一生（たまご→よう虫→さなぎ→成虫、約1年） |
| 4 | `04_tips.svg` | 元気に育てる 4つの コツ（日かげ・マット・ゼリー・のぼり木） |
| 5 | `05_zukan.svg` | かぶとむし 大けんきゅう（体のつくり＋まめちしき） |

`*.png` は各ポスターのプレビュー画像です（スマホ表示やChatGPTとの比べっこ用）。

## 見かた・印刷のしかた

- **まとめて見る／印刷する**: `index.html` をブラウザで開く →「🖨 印刷する」ボタン。1まいずつページ分けして出ます。
- **1まいだけ**: SVGファイルをブラウザにドラッグして開く → 印刷。
- SVGはベクター形式なので、拡大しても画質が落ちません。大きく印刷したいときに最適です。

## フォントについて

文字は `Hiragino Maru Gothic ProN / Yu Gothic / Meiryo / Noto Sans CJK JP` の順で表示されます。Mac・Windowsならそのままきれいな丸ゴシックで出ます。
